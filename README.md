Тапсырмалар менеджері (To-Do)

Жоба туралы

«Тапсырмалар менеджері» - PHP және MySQL технологиялары арқылы әзірленетін веб-қосымша. Жобаның негізгі мақсаты - пайдаланушыларға өз тапсырмаларын құруға, сақтауға, өңдеуге және олардың орындалу барысын бақылауға мүмкіндік беру.

Жобаның мақсаты

Тапсырмаларды тиімді жоспарлауға және оларды уақытында орындауды бақылауға арналған ыңғайлы веб-қосымша жасау.

Қолданылатын технологиялар

* HTML - веб-беттің құрылымын жасау.
* CSS - сайттың дизайнын безендіру.
* JavaScript - интерфейстің интерактивтілігін қамтамасыз ету.
* PHP - серверлік бөлікті әзірлеу.
* MySQL - мәліметтерді сақтау.
* GitHub - жобаның кодын сақтау және өзгерістерді бақылау.

Негізгі мүмкіндіктері

* Пайдаланушыны тіркеу және жүйеге кіру.
* Жаңа тапсырма қосу.
* Тапсырмалар тізімін қарау.
* Тапсырмаларды өңдеу және жою.
* Тапсырманың орындалу мәртебесін өзгерту.
* Тапсырмаларды атауы бойынша іздеу.
* Тапсырмаларды мәртебесі бойынша сүзу.
* Тапсырмалардың орындалу мерзімін көрсету.
* Пайдаланушы мәліметтерін қауіпсіз сақтау.

Дерекқор құрылымы

Жоба MySQL дерекқорындағы үш негізгі кестеден тұрады:

1. users - пайдаланушылар туралы мәліметтер.
2. tasks - тапсырмалар туралы мәліметтер.
3. categories - тапсырмалар санаттары.

Жобаның беттері

* index.php - басты бет.
* register.php - тіркелу беті.
* login.php - жүйеге кіру беті.
* tasks.php - тапсырмалар тізімі.
* add_task.php - тапсырма қосу беті.
* edit_task.php - тапсырманы өңдеу.
* delete_task.php - тапсырманы жою.
* logout.php - жүйеден шығу.

Қауіпсіздік

Жобада құпиясөздерді хэштеу, енгізілген мәліметтерді тексеру және PDO арқылы дайындалған SQL сұраныстарын қолдану қарастырылады. Сонымен қатар пайдаланушылардың жеке тапсырмаларына рұқсатсыз қол жеткізуден қорғау жоспарланады.

Жобаның орындалу кезеңі

Бұл кезеңде жобаның тақырыбы, мақсаты, негізгі функциялары, сайт беттері және дерекқор құрылымы анықталады. GitHub репозиторийі құрылады және жобаның сипаттамасы осы README.md файлына енгізіледі.
